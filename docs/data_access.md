The table records provenance. It does not verify or grant access/redistribution
rights. Follow the original providers' current terms and any applicable agreements.
An upload-site license or a paper citation alone does not establish that all
upstream rights have been cleared.

Document archive version/hash, access date, metadata source, preprocessing,
exclusions, labels, group identifiers, and resulting split counts. Do not substitute
canonical collection counts for the processed experimental cohorts. See the README
for target mappings, including abnormal-only MIAS and strict BI-RADS INbreast.

Keep raw archives, cached images, clinical metadata, prediction-level identifiers,
and machine-specific path lists outside the public repository by default. Publish
only materials whose rights and contents have been reviewed. Aggregate split counts
and image-free preparation instructions are useful alternatives.
